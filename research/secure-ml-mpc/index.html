FPGA-accelerated secure machine learning

Multi-party computation on FPGA SmartNICs with RDMA

Multi-party computation (MPC) lets several parties train or evaluate a model jointly without revealing their inputs, but every multiplication needs a round of communication between parties. This project runs the MPC engine on FPGA SmartNICs and connects them with the Coyote RDMA stack, so secret-shared data moves between parties without touching the host CPU and communication overlaps with computation.
