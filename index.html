Xiteng Yao

PhD Candidate, Electrical and Computer Engineering, Boston University

I am a PhD candidate in Computer Engineering at Boston University, advised by Prof. Martin Herbordt in the CAAD Lab (Computer Architecture and Automated Design), expecting to graduate in May 2027.

My research is on systems for large language models: where computation, state, and coordination should live in distributed LLM training and inference. I work across the stack, from programmable switches and SmartNIC datapaths, through collective communication and RDMA, to GPU performance modeling and LLM serving runtimes. I also build FPGA accelerators for secure machine learning, and ask how to measure what really helps LLM agents that optimize code.

I have interned at Arm as an AI Research Scientist Intern, working on attention–FFN disaggregated LLM inference, and at Amazon Web Services as an Applied Scientist Intern, where I built KernelSight-LM, a kernel-level LLM inference simulator. More in experience and the CV.

Research interests: LLM training and inference systems · SmartNIC/FPGA acceleration · programmable and stateful switches · collective communication · GPU performance modeling · AI for performance engineering · privacy-preserving computation.

selected publications

  1. HPEC
    ACBench: A Benchmark Suite for Auditing Retry and Profiling Feedback in LLM-Driven Code Optimization
    Xiteng Yao*, Ziyuan Chu*, Feng Tai*, Bangjie Xue, Yigong Hu, and Martin Herbordt
    In 2026 IEEE High Performance Extreme Computing Conference (HPEC), 2026
    Abstract Cite PDF Code

    ACBench is a benchmark of 14 code-optimization tasks drawn from merged pull requests in six production Go codebases. It separates the value of feedback (application errors, benchmark summaries, CPU profiles) from the value of simply getting more attempts, and tracks when a run can actually use that feedback.

  2. HPEC
    PoolStateLens: Evaluating the Performance of an On-Switch Memory Pool for LLM Training
    Xiteng Yao and Martin Herbordt
    In 2026 IEEE High Performance Extreme Computing Conference (HPEC), 2026
    Abstract Cite PDF

    A switch-attached memory pool can hold LLM training state (parameters, master weights, optimizer moments) so capacity grows independently of GPU count. PoolStateLens is a measurement-grounded analytical method that compares this design with FSDP over a full training iteration, using GB200/NVLink-5 measurements and ASTRA-sim checks. Pooling can reduce the GPU memory needed for training state, but matching FSDP speed requires about 7.9 TB/s of aggregate raw state bandwidth in a controlled 7B, 32-GPU case, under the model’s assumptions.

  3. HEART
    SmartFuse-LLM: Fusing Computation into Collectives for Efficient Tensor-Parallel LLM Systems
    Xiteng Yao, Bangjie Xue, Anthony Skjellum, and Martin Herbordt
    In Proceedings of the 16th International Symposium on Highly Efficient Accelerators and Reconfigurable Technologies (HEART), 2026
    Abstract ACM DL Cite

    SmartFuse-LLM is an FPGA-based switch datapath that fuses collective communication, residual addition, and RMSNorm at tensor-parallel boundaries, removing a network round trip and GPU-side normalization. GPU profiling and RTL co-simulation project 50.5% lower per-boundary latency.

  4. arXiv
    KernelSight-LM: A Kernel-Level LLM Inference Simulator
    Xiteng Yao, Taeho Kim, Hengzhi Pei, Xinle Liu, Kyle Ulrich, Leonard Lausen, Ashish Khetan, Xiang Song, George Karypis, and Martin Herbordt
    arXiv preprint arXiv:2606.28565, 2026
    Abstract arXiv Cite

    KernelSight-LM is a GPU-kernel-aware profiling and simulation toolchain that combines kernel-latency, communication, and host-overhead models in a discrete-event scheduler to predict end-to-end LLM inference latency and throughput. Across six model families it reaches 2.7% median throughput-prediction error in the target-measured setting.

  5. HPEC
    Accelerating Multi-Party Computation Using Heterogeneous Systems
    Outstanding Student Paper Award
    Xiteng Yao, Shining Yang, Mayank Varia, and Martin Herbordt
    In 2025 IEEE High Performance Extreme Computing Conference (HPEC), 2025
    Abstract IEEE Xplore Cite

    An FPGA architecture for secure machine-learning training with multi-party computation that integrates the Coyote RDMA stack on AMD FPGA SmartNICs for CPU-bypass transfers, overlapping communication with computation and reaching a 2.1× convolution-layer speedup over existing MPC frameworks.

  6. ICS
    SmartNIC-GPU-CPU Heterogeneous System for Large Machine Learning Model with Software-Hardware Codesign
    Anqi Guo, Yuchen Hao, Xiteng Yao, Shining Yang, Jianyu Huang, Tong Geng, and Martin Herbordt
    In Proceedings of the 39th ACM International Conference on Supercomputing (ICS), 2025
    Abstract ACM DL Cite

    A SmartNIC-based design for ZeRO training that uses parameter prefetching, buffering, and dynamic scheduling to overlap GPU/CPU computation with communication. Hardware-calibrated cycle-accurate simulation projects over 1.6× training throughput for a 100B-parameter model versus GPU-CPU offload with ordinary NICs.
