Programmable switches for distributed LLM systems

Fusing computation and placing state inside the network fabric

Distributed LLM training and inference push data through the network at every layer. This project asks which work can move into the switch that the data already passes through, and when doing so removes more critical-path time than it adds.

SmartFuse-LLM: fusing computation into collectives

With tensor and sequence parallelism, every layer boundary does a reduce-scatter, a small residual add and RMSNorm on each GPU, and then an all-gather. SmartFuse-LLM moves the add and RMSNorm into an FPGA switch datapath, so the switch returns normalized activations directly and one of the two network round trips disappears. Paper (ACM DL)

PoolStateLens: evaluating an on-switch memory pool for training state

Fully sharded training spreads parameters and optimizer state across GPUs, so memory capacity grows only by adding GPUs. A switch-attached memory pool, proposed in prior work, can hold that state instead: the switch multicasts parameters to GPUs, reduces gradients back, and an optimizer beside the pool applies the update. PoolStateLens is a measurement-grounded model, built on GB200 NVL72 measurements and ASTRA-sim checks, that asks how fast such a pool must be to keep up with FSDP. PDF

    Xiteng Yao, Bangjie Xue, Anthony Skjellum, and Martin Herbordt
    In Proceedings of the 16th International Symposium on Highly Efficient Accelerators and Reconfigurable Technologies (HEART), 2026
    Abstract ACM DL Cite

    SmartFuse-LLM is an FPGA-based switch datapath that fuses collective communication, residual addition, and RMSNorm at tensor-parallel boundaries, removing a network round trip and GPU-side normalization. GPU profiling and RTL co-simulation project 50.5% lower per-boundary latency.

  2. HPEC
    PoolStateLens: Evaluating the Performance of an On-Switch Memory Pool for LLM Training
    Xiteng Yao and Martin Herbordt
    In 2026 IEEE High Performance Extreme Computing Conference (HPEC), 2026
    Abstract Cite PDF

    A switch-attached memory pool can hold LLM training state (parameters, master weights, optimizer moments) so capacity grows independently of GPU count. PoolStateLens is a measurement-grounded analytical method that compares this design with FSDP over a full training iteration, using GB200/NVLink-5 measurements and ASTRA-sim checks. Pooling can reduce the GPU memory needed for training state, but matching FSDP speed requires about 7.9 TB/s of aggregate raw state bandwidth in a controlled 7B, 32-GPU case, under the model’s assumptions.
