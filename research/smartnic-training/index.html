SmartNIC offload for large-model training

Overlapping ZeRO communication with GPU and CPU computation

ZeRO-style training repeatedly gathers parameters from other GPUs and offloads state to host memory, so the GPU often waits on data movement. This work puts a SmartNIC in that data path: it prefetches and buffers parameters from the network and host memory and schedules their delivery to the GPU, overlapping communication with GPU and CPU computation and reducing duplicate parameter gathers.     SmartNIC-GPU-CPU Heterogeneous System for Large Machine Learning Model with Software-Hardware Codesign
    Anqi Guo, Yuchen Hao, Xiteng Yao, Shining Yang, Jianyu Huang, Tong Geng, and Martin Herbordt
    In Proceedings of the 39th ACM International Conference on Supercomputing (ICS), 2025
    Abstract ACM DL Cite

    A SmartNIC-based design for ZeRO training that uses parameter prefetching, buffering, and dynamic scheduling to overlap GPU/CPU computation with communication. Hardware-calibrated cycle-accurate simulation projects over 1.6× training throughput for a 100B-parameter model versus GPU-CPU offload with ordinary NICs.
